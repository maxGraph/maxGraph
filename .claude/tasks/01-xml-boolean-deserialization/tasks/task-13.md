# Task: Extending guide, and links from the codec and configuration pages

## Problem
Both halves of this subject are undocumented on the website. Extending the style types by module augmentation is
described only in `CHANGELOG.md:37-58` and exercised by a compile check in
`packages/ts-support/src/module-augmentation.ts`, and nothing tells a reader that a custom boolean property has to be
declared to the codecs to decode correctly. Grepping `packages/website/docs` for augment returns nothing.

## Proposed Solution
Add a guide page where both halves meet, so a reader who extends the style types learns in one place what that buys
them at the type level and what it requires of them at the codec level. Have the codec and global configuration pages
link to it rather than repeat its examples, so the pages cannot drift apart.

## Dependencies
- Task 12: the guide documents the exported names, so those must be settled first.
- Open decision 3 in `plan.md`: its outcome is what the limits section has to state.

## Context
- `plan.md`, step 4, sections `extending.md`, `codecs.md` and `global-configuration.md`, which fix the five sections
  of the page and the front matter convention: `sidebar_position: 10` like every page except three, an autogenerated
  sidebar (`packages/website/sidebars.ts:14`) and the category label taken from `usage/_category_.json`, so there is
  no wiring to do.
- State before any mechanics that a custom property of any other type needs nothing at all: the decoders coerce by
  the shape of the value, so a number stays a number and a string stays a string. Booleans are the single exception,
  which is the reason they alone have to be declared.
- The sentence at `packages/website/docs/usage/codecs.md:212` documents the current behaviour as intended. It stays
  true of the encode side, so it must be qualified rather than deleted.
- The natural entry point for the link is the custom codec section at `packages/website/docs/usage/codecs.md:162-177`.
- The styles section at `packages/website/docs/usage/global-configuration.md:53-105` already lists the five style
  registries and their unregister functions, so the new pair belongs beside them.

## Success Criteria
- The guide covers both halves of the subject, and states the per-codec alternative and the limits.
- The codec and global configuration pages link to the guide and repeat none of its examples.
- The corrected sentence on the codec page no longer reads as if decoding produced numbers.
